# 《晴汐小镇：一间寿司屋》

原创 3D 小镇生活 × 寿司店经营游戏｜概念设计 v0.1

本文件是前期设计提案，不代表游戏已实现。默认先面向 PC 单人体验，支持手柄；主机移植和联机留待验证后决定。

## 1. 一句话与情绪

你回到一座依山临海的小镇，重新打开外婆留下的寿司店。白天沿溪钓鱼、寻找野菜，傍晚把当季食材做成料理，慢慢认识邻居，也让停办多年的海湾花火大会重新亮起来。

玩家真正经营的是“一间让大家愿意回来的店”。第一道拿手菜、第一次有人记得你的口味、第一盏重新点亮的街灯，最后汇成映照整座海湾的烟花。

体验关键词：清透、可爱、有烟火气、自由但不迷失、有轻微惆怅但最终温暖。参考作品仅提供光影、生活节奏和童趣的方向；角色、建筑、图形符号、音乐和剧情均采用原创设计。

## 2. 产品边界与镜头

| 项目 | 设计目标 |
|---|---|
| 类型 | 3D 小型开放世界、生活模拟、轻经营、关系叙事 |
| 世界 | 一张约 0.6–0.8 km² 的紧凑地图，七个相连片区；室内短加载 |
| 自由度 | 可以攀走缓坡、沿步道采集、进入公共建筑；不做战斗、车辆和无限地形破坏 |
| 镜头 | 常规第三人称，支持旋转和两档距离；室内自动抬高；装修切换俯视网格 |
| 美术 | 风格化 3D，绘制纹理、柔和投影、局部赛璐璐人物、高层次天空 |
| 时间 | 游戏日约 24 分钟，可调 0.5/1/1.5 倍；菜单、对话、装修暂停时间 |
| 日历 | 每季 28 天，一年 112 天；睡觉可主动结束当天，不与真实时间绑定 |
| 节奏 | 20–40 分钟完成一个生活小目标；完整主线初估 25–35 小时，需原型校准 |
| 压力 | 无饥饿惩罚、无强制房贷、无离线损失；体力耗尽只降低采集效率，可就地休息 |

自由活动可跳过经营日。不开店不扣租金、不掉友情；库存与预订会提示影响。关键剧情不因漏玩某天永久失效。

## 4. 三条互相支撑的循环

**一天：** 看天气和留言 → 钓鱼/种菜/进货 → 从订单选择今日菜单 → 备料并开店 → 与食客交谈 → 结算、整理小屋、安排明天。玩家随时可以把一天改成纯探索日。

**一周：** 遇见当季新品种 → 实验菜谱 → 完成村民愿望 → 获得工具或装饰 → 扩充店铺选择 → 参与周末活动。

**长期：** 收集外婆食谱里的零散批注 → 理解村民与旧祭典的关系 → 建立花火筹备小组 → 用自己经营所得和人际关系办成大会 → 在故事结束后继续自由生活。

主线进度分为店铺、邻里、祭典三项记录。玩家通过多条等价路径满足条件，例如提供活动食材、参与布置、承担一段餐饮服务都能贡献筹备值，不强迫精通所有小游戏。

## 5. 主线：把“明年再见”重新说出口

外婆的店已经停业。镇上几年前因风灾损坏了祭典设施，之后客源减少、组织者也渐渐散去；花火师朔因父亲离世，不愿再接下大会。主线是修复公共空间与人与人的连接，避免靠单次巨额捐款解决所有问题。

| 章 | 故事与可玩任务 | 解锁与情绪 |
|---|---|---|
| 1 门帘重新挂起 | 整理店铺；从菜农处获得第一篮菜；钓到第一条可食鱼；做三份握寿司 | 探索、基础料理、店铺试营业；被邻居记住名字 |
| 2 今日推荐 | 为三种客人口味设计菜单；用采集或采购交付第一批委托 | 菜谱笔记、进货、公告栏；理解经营选择 |
| 3 食谱里的空白 | 找到外婆给不同村民留下的食谱页；完成三条邻里故事的第一阶段 | 家具目录、住宅购买机会；小镇逐渐有私人意义 |
| 4 褪色的海报 | 找出旧大会照片；与朔一起调查会场；协助清理步道 | 祭典筹备板；知道大家为何不再提起花火 |
| 5 大家的一点点 | 渔师协调码头、木工维修摊架、孩子制作愿望纸；玩家任选两类贡献 | 会场分区与摊位装饰；关系成果变为实物 |
| 6 夏日特制菜单 | 开发一道能代表今年夏天的招牌菜；服务筹备组晚餐 | 大会预约；研究成果被肯定 |
| 7 风来的前夜 | 天气影响彩排；整理餐饮供应与防雨布；与朔决定是否改期 | 合法专业人员负责烟花，玩家只做布置和餐饮；共同承担责任 |
| 8 海湾开花的夜晚 | 日间布置 → 夜市经营 → 与村民会合 → 观看分段花火 → 海边余韵 | 主线落幕、纪念食谱、合影、自由生活继续 |

前六章可跨季推进，不要求第一年完成。大会放在准备就绪后的夏季窗口；如果当年已过夏季，可选择正常生活到下一夏，或经明确确认快进至下一夏的筹备周。快进结算作物为种子返还、保留库存且不扣友情，不默默模拟离线收入。夏季活动每年重开，错过普通活动可参加下一届；核心主线章节在筹备板保留。

### 花火高潮的具体演出

1. **16:00–18:00，大家的准备。** 会场出现已经帮助过的村民与布置。支线改变灯笼、摊位和对话，不改变主线能否结局。
2. **18:00–20:00，最后一场营业。** 玩家选定 3 道便于外带的料理；可选择轻松经营或交给助手结算，让叙事高潮不被操作失败打断。
3. **20:00，灯光降低。** 刚才的热闹声音渐弱。海浪、脚步、木桥声清楚起来，玩家自己走向观景位置。
4. **20:05，第一朵。** 少量金色花火在远海上升，朔讲完父亲留下的一句话；可保持自由镜头，也可启用电影镜头。
5. **中段，愿望回响。** 音乐动机与店里常听见的旋律相接。朋友的任务成果被拍到：孩子的愿望灯、修好的摊架、长者留下的空座。
6. **终段，潮声之花。** 金、杏桃、海玻璃青三段大花火层层铺满海湾，停顿一拍后出现宽幅金雨。高潮约 60–90 秒，完整演出约 4 分钟，需视节奏测试调整。
7. **结束后，留白。** 不立即弹出满屏奖励；允许散步和交谈。最后获得全镇合影、花火食谱与可摆放的纪念灯笼。

花火支持降低闪烁、减弱亮度、关闭震动与跳过演出；跳过照常获得结果。交互区与专业发射区之间以海湾隔离，不设计自制火药玩法。

## 6. 采集、种植与料理

### 钓鱼

海、河、池塘三类水域；季节、时段、天气影响鱼池。先判断鱼影，再用节奏控线；提供长按辅助、扩大时机窗与自动成功选项。初版目标 12 种鱼，分别配置收藏记录、食材类型、售价和生态信息。珍稀观赏鱼只收藏或放生，不默认拿所有水生动物做寿司。

示例：竹荚鱼是早期经济鱼；鲭鱼需要解锁“醋渍”料理标签；鲈鱼与海虾对应夏日菜单。河鱼参与熟食料理，避免把所有野外食材笼统呈现为可生食。食材处理只用游戏标签表示，不作为现实食安教学。

### 抓昆虫

林缘、花坛、树干、夜灯四类观察点；首版 12 种。虫鸣提供方向提示，挥网有距离和背后接近机制，可开启轮廓辅助。昆虫进入观察馆、记录册、放生或村民自然观察任务，不作为寿司原料。完成观察馆阶段目标可获得标本画、植物盆景和自然主题家具。

### 野菜与菜园

6 种可食野外采集物、8 种种植作物。采集点重生且有上限；每类以稳定的叶形和图鉴提示辨识。不可食植物不允许当食材，幼体可选择保留。作物流程为整地、播种、浇水、收获；雨天自动浇水。肥料提高品质，不是必需品。忘记浇水主要延后成熟，换季前明确提示可收回种子或移入温室。

示例作物：黄瓜、萝卜、紫苏、小葱、茄子、南瓜、菠菜、稻米。首个可玩版只做黄瓜和萝卜。稻米用一个简化水田种植区表现，不把普通旱地模型直接换贴图。海苔、米、酱油等基础品可持续进货，玩家种植主要提供季节特色与品质收益。

### 菜谱研究：有规则的试验

菜谱由“主料 × 配菜 × 工艺”构成。笔记按标签给出线索，如油脂鱼、清香菜、醋渍；已知不兼容组合在投入材料前给出提醒。研究仅消耗一份试制材料，失败留下口味记录，不损失整批库存。

首版目标 18 道固定可视菜品，允许用兼容食材替换统计标签；不会为每种组合自动生成独立模型。发现配方后按标准菜品模型显示，并在菜单文字中注明变体。

| 菜品方向 | 获取与玩法角色 |
|---|---|
| 竹荚鱼握寿司、醋渍鲭鱼握、鲈鱼握 | 入门、醋渍解锁、夏季鱼类路线 |
| 海虾握、炙烤鲭鱼握、玉子握 | 进货稳定菜、工艺进阶、低风险补货 |
| 黄瓜细卷、紫苏野菜卷、腌萝卜卷 | 自种与采集路线，覆盖素食偏好 |
| 烤茄子握、南瓜小卷、菠菜芝麻卷 | 秋冬菜单与熟食路线 |
| 春芽小碗、夏潮散寿司、秋实散寿司、冬日热茶泡饭 | 四季主题与库存利用 |
| 外婆的便当寿司、晴汐花火拼盘 | 关系线与主线招牌菜 |

## 7. 寿司店经营：可决定，而非忙到窒息

营业前选择 3–5 道今日菜单、定价档位和座位安排。备料消耗库存，进入服务阶段后，玩家可以在切配、捏制、上菜三个操作之间切换；熟练菜可交给助手，首个版本先以明确的自动制作按钮模拟助手。

客人有口味、预算、耐心、谈话主题；满意度来自正确口味、合理等待和整洁。特殊客人只在经营结束后触发长对话。服务小游戏有节奏反馈但无连击强制；轻松模式无客人催促惩罚。

**进货与保鲜：** 基础商品每日可买；高品质鱼和特别香料按日轮换。鲜食材用“当日 / 冷藏 / 腌制”简化品质，而非按分钟腐败；睡前提示处理去向，可转熟食、腌制或捐给社区餐桌。预订与每日限购防止无限买卖套利。

### 用于原型测试的经济样例

| 数值 | 初始假设 |
|---|---|
| 普通握寿司售价 | 90–140 潮贝币/份 |
| 招牌菜售价 | 160–220 潮贝币/份 |
| 采购食材成本 | 约售价的 30%–45% |
| 初期营业规模 | 8–12 位客人，平均每位 1–2 份 |
| 原型示例营业 | 10 客 × 1.5 份 × 120 = 1,800；采购 600、当次耗材 120，现金结余 1,080 |
| 野外食材收益 | 节约现金但消耗玩家时间；不宣称采集成本为零 |
| 第一间小屋 | 约 12,000，约 10–15 次普通营业；此前可免费住店铺阁楼 |
| 店铺首次扩展 | 约 8,000，与买房构成可理解的优先选择 |

这些数字是测试起点，不是已完成的平衡结果。统计每分钟收入、食材浪费和平均操作量；若出现“只能钓一种鱼最划算”，用每日需求、菜单偏好和多样性奖励调整。无强制日息贷款，无随机抽卡装修。

## 8. 买房、装修与关系

玩家先住阁楼，再买小屋；后期可扩一间房和庭院。装修采用 0.25 m 基础网格，桌面物品可吸附到家具插槽；支持旋转、撤销、存回仓库。墙纸与地板独立更换。角色通路需留至少 0.9 m，系统以可通行预览提示，防止把自己卡住。营业动线也参与店铺装修，必要设备采用固定槽位。

首版三个家具主题：原木海风、薄荷和室、夏日祭典。家具从商店、木工制作、关系任务和季节活动获取。房屋评价奖励风格一致性与生活感，不要求唯一最优摆法。

友情四阶段为相识、熟悉、信任、知己。主要由共同事件和完成心愿推进；重复送同款礼物收益递减，不做每日不送礼就掉好感。十位主村民各有三段关系任务和独立日程；另有不具完整关系线的通用顾客。

| 村民 | 职能与外形关键词 | 三段支线的核心变化 |
|---|---|---|
| 澪，年轻渔师 | 晒痕、青绿短外套、橙浮标 | 找回钓具 → 观察鱼群 → 为大会调度小船 |
| 千代，菜农 | 大草帽、鼠尾草围裙、竹篮 | 救回幼苗 → 找回旧种 → 共享季节菜篮 |
| 朔，花火师 | 深靛工作服、灰黑短发、折叠图纸 | 修复灯架 → 说起父亲 → 决定重办大会 |
| 凪，杂货店主 | 圆眼镜、杏色罩衫、账本 | 整理库存 → 解决滞销 → 提供夜市摊位 |
| 芽衣，木工 | 工装短裤、皮工具袋 | 找合适木料 → 修旧家具 → 制作纪念长椅 |
| 和叶，观察馆馆长 | 浅紫开衫、叶片胸针 | 建昆虫记录 → 寻找萤火 → 做夜间自然导览 |
| 遥，邮差 | 浅蓝上衣、斜挎邮包 | 送错地址 → 找旧住户 → 收到远方回信 |
| 律，音乐人 | 宽松白衫、绿色琴盒 | 寻找声音 → 与邻居合奏 → 为花火作主题旋律 |
| 纱纱，小学生 | 黄上衣、捕虫小包 | 找到第一只蝉 → 画观察手册 → 发起不伤害昆虫的比赛 |
| 悠太，小学生 | 条纹上衣、纸风车 | 看云猜雨 → 制作天气本 → 成为祭典小小播报员 |

白猫“饭团”是店门口的常客，单耳姜黄，不承担复杂宠物养成。它会引导玩家发现小路和食谱纸角；不把推进任务绑定为每天投喂。

### 可选委托举例

“今天不想吃鱼”：为长者做一道素食卷；“木桥下的银光”：雨后观察鱼影并记录；“缺了一角的饭盒”：找木工修旧物；“一封没有门牌的信”：根据三条场景线索投递；“店门口的影子”：顺着饭团的脚印找到晒太阳处；“给不敢回家的人留一盏灯”：夜间餐饮与关系对话；“花火前的第一声蝉”：完成观察而非交付活虫；“从海上看一眼”：协助澪准备可供观众使用的港口座椅。

常规委托可刷新，人物故事只推进一次。主线、关系事件、随机委托分别标识，不能用重复跑腿替代主线内容。

## 10. 首个可玩版本：用 7 天证明核心乐趣

**范围：** 一个连续户外区（商店街河岸、短钓点、两块菜地）、寿司店室内、玩家小屋室内；玩家一套基础造型，澪/千代/朔/凪四位村民、两种通用顾客和饭团；3 种鱼、2 种昆虫、1 种野菜、2 种作物、5 道菜、8 件可摆家具；缩短版花火与三段任务。

**七天测试动线：** 第 1 天重开店铺；第 2 天钓鱼和进货；第 3 天研究紫苏野菜卷；第 4 天种菜并布置小屋；第 5 天完成村民委托；第 6 天准备夜市菜单；第 7 天举办小型花火晚会。采用夏季测试日历，作物成熟时间单独配置。该顺序是引导方案，玩家可以自由安排。

**必须验证的闭环：** 获得食材 → 入库 → 研究或选择菜谱 → 开店售卖 → 支出与收益正确 → 购买并摆放家具 → 保存/读档恢复库存、友情、作物和家具 → 任务成果在花火现场可见。

**体验验收目标：** 新玩家 10 分钟内理解第一份寿司的来源；30 分钟内有一次主动选择采集或采购；至少一次经营后买得起有意义的装饰；不开店一天仍有事情可做；花火能看见自己参与留下的变化。目标是招募测试验证，尚无实测结果。

**暂不制作：** 完整四季、全部支线、全地图、完整房屋扩建、复杂员工 AI、多人、潜水、载具、战斗、恋爱结婚、大型动态水体模拟。

技术引擎、开发周期与预算需结合团队确定。建议先用灰盒和少量正式资产验证摄像机、移动、经营与读档，再决定完整制作；本提案不直接承诺首发规模和成本。
